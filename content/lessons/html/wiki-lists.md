# 항목의 관계에 맞는 목록

## 학습 목표

항목의 순서와 이름·설명 관계에 따라 ul·ol·dl을 선택할 수 있습니다.

## 한줄 요약

순서 없는 항목은 ul, 순서가 의미를 바꾸는 항목은 ol, 이름과 설명의 짝은 dl로 나타냅니다.

## 먼저 확인할 개념

[HTML의 역할과 요소 읽기](#/learn/html/wiki-markup)의 관계를 알고 있으면 이 문서를 읽기 쉽습니다.

## 목적부터 묻는 선택 순서

| 먼저 물을 질문 | 알맞은 관계 | 먼저 검토할 요소 |
| --- | --- | --- |
| 순서를 바꾸면 뜻이 달라지는가? | 단계·순위 | `ol` |
| 순서를 바꿔도 뜻이 같은가? | 항목 모음 | `ul` |
| 이름과 설명을 짝지어야 하는가? | 용어와 설명, 이름과 값 | `dl` |

## 목록은 항목 사이의 관계를 보여 준다

### 순서가 중요하지 않은 준비물

```html
<h2>준비물</h2>
<ul>
  <li>이번 달 책</li>
  <li>독서 메모</li>
  <li>필기구</li>
</ul>
```

세 항목의 순서를 바꿔도 준비물이라는 뜻은 같다.
그래서 `ul`을 사용한다.

### 순서가 중요한 신청 단계

```html
<h2>신청 순서</h2>
<ol>
  <li>신청서를 작성한다.</li>
  <li>확인 메일을 읽는다.</li>
  <li>모임 날짜를 달력에 적는다.</li>
</ol>
```

단계의 순서를 바꾸면 실제 진행 순서가 달라지므로 `ol`을 사용한다.

### 이름과 설명을 잇는 정보

```html
<dl>
  <dt>장소</dt>
  <dd>별빛도서관 2층 모임방</dd>
  <dt>시간</dt>
  <dd>매달 셋째 토요일 오후 7시</dd>
</dl>
```

`dl`은 단순한 글머리표가 아니라 이름과 설명 또는 이름과 값을 연결한다.

목록 요소는 정보 관계를 나타내므로 들여쓰기나 화면 배치만을 위해 사용하지 않는다.

## 핵심 질문 답

준비물은 순서를 바꿔도 뜻이 유지되어 ul을, 신청 단계는 순서가 바뀌면 진행이 달라져 ol을 사용합니다.
장소와 시간처럼 이름에 설명이나 값을 연결할 때는 dl 안의 dt와 dd로 짝을 표현합니다.
들여쓰기나 글머리표 모양이 아니라 정보의 관계를 기준으로 선택합니다.
