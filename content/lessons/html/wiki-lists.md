# 목록과 표: 정보 관계에 맞는 요소

## 학습 목표

- 항목의 순서와 이름·설명 관계에 따라 ul·ol·dl을 선택할 수 있습니다.
- 행과 열로 연결되는 데이터를 목록과 구분해 table로 표현할 수 있습니다.
- caption·th·scope로 표 제목과 머리글 관계를 설명할 수 있습니다.

## 선수 개념

[HTML 시작하기: 요소와 문서의 기본 골격](#/learn/html/wiki-markup)의 관계를 알고 있으면 이 문서를 읽기 쉽습니다.

## 목록과 표의 관계

목록은 항목을 모으거나 이름과 설명을 연결하고 표는 행과 열이 서로 설명하는 데이터를 나타냅니다.
앞 문서에서 이미지와 미디어에 필요한 대체 정보를 정했습니다.
이제 같은 책모임의 준비물·신청 순서·일정을 정리해 보겠습니다.

## 목록의 선택 기준

| 먼저 물을 질문 | 알맞은 관계 | 먼저 검토할 요소 |
| --- | --- | --- |
| 순서를 바꾸면 뜻이 달라지는가? | 단계·순위 | `ol` |
| 순서를 바꿔도 뜻이 같은가? | 항목 모음 | `ul` |
| 이름과 설명을 짝지어야 하는가? | 용어와 설명, 이름과 값 | `dl` |

## 목록의 종류와 사용법

### 순서가 중요하지 않은 준비물

```html
<h2>준비물</h2>
<ul>
  <li>이번 달 책</li>
  <li>독서 메모</li>
  <li>필기구</li>
</ul>
```

세 항목의 순서를 바꿔도 준비물이라는 뜻은 같습니다.
그래서 `ul`을 사용합니다.

### 순서가 중요한 신청 단계

```html
<h2>신청 순서</h2>
<ol>
  <li>신청서를 작성한다.</li>
  <li>확인 메일을 읽는다.</li>
  <li>모임 날짜를 달력에 적는다.</li>
</ol>
```

단계의 순서를 바꾸면 실제 진행 순서가 달라지므로 `ol`을 사용합니다.

### 이름과 설명을 잇는 정보

```html
<dl>
  <dt>장소</dt>
  <dd>별빛도서관 2층 모임방</dd>
  <dt>시간</dt>
  <dd>매달 셋째 토요일 오후 7시</dd>
</dl>
```

`dl`은 단순한 글머리표가 아니라 이름과 설명 또는 이름과 값을 연결합니다.

목록 요소는 정보 관계를 나타내므로 들여쓰기나 화면 배치만을 위해 사용하지 않습니다.

준비물과 절차는 목록으로 표현했습니다.
날짜마다 책과 장소를 함께 비교해야 한다면 행과 열의 관계가 있는 표를 사용합니다.

---

## 표의 구조와 머리글

달력처럼 보이게 만들기 위해서가 아니라, 각 날짜와 책과 장소가 행과 열로 연결될 때 `table`을 사용합니다.

```html
<table>
  <caption>2026년 가을 책모임 일정</caption>
  <thead>
    <tr>
      <th scope="col">날짜</th>
      <th scope="col">책</th>
      <th scope="col">장소</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <th scope="row">9월 20일</th>
      <td>느린 밤의 산책</td>
      <td>별빛도서관</td>
    </tr>
    <tr>
      <th scope="row">10월 18일</th>
      <td>작은 정원의 편지</td>
      <td>달빛문화실</td>
    </tr>
  </tbody>
</table>
```

- `caption`은 표 전체가 무엇인지 알려 줍니다.
- `thead`는 머리글 행 묶음, `tbody`는 본문 데이터 행 묶음입니다.
- `th`는 다른 칸을 설명하는 머리글 칸입니다.
- 단순한 표에서 `scope="col"`은 열, `scope="row"`는 행을 설명한다고 밝힙니다.
- `td`는 데이터 칸입니다.

`scope`는 단순한 표에서 행과 열의 관계를 알려 주는 데 도움이 됩니다.
머리글 관계가 복잡한 표는 `scope` 하나만으로 충분한지 따로 확인해야 합니다.

화면의 두 상자를 나란히 놓기 위해 표를 쓰지 않습니다.
화면 배치는 CSS의 역할입니다.

## 정리

- 순서가 의미를 바꾸면 ol을 쓰고 순서 없는 항목에는 ul을 사용합니다.
- 이름과 설명의 짝은 dl·dt·dd로 연결합니다.
- 행과 열이 서로 설명하는 데이터에는 표 제목과 머리글을 갖춘 table을 사용합니다.

## 핵심 질문 답

준비물은 순서를 바꿔도 뜻이 유지되어 ul을, 신청 단계는 순서가 바뀌면 진행이 달라져 ol을 사용합니다.
장소와 시간처럼 이름에 설명이나 값을 연결할 때는 dl 안의 dt와 dd로 짝을 표현합니다.
들여쓰기나 글머리표 모양이 아니라 정보의 관계를 기준으로 선택합니다.
날짜·책·장소처럼 행과 열이 서로 연결된 데이터에 table을 씁니다.
caption은 표 전체를 설명하고 th는 머리글, td는 데이터이며 단순한 표에서 scope=col은 열, scope=row는 행을 설명합니다.
복잡한 머리글은 추가 관계 검토가 필요하고 화면 상자를 나란히 배치하는 일에는 표 대신 CSS를 사용합니다.
