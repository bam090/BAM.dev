# 01. 문서 구조와 의미 있는 요소

## 학습 목표

- HTML 문서의 `html`, `head`, `body`가 맡는 역할을 자신의 말로 설명할 수 있습니다.
- `header`, `nav`, `main`, `section`을 화면 모양이 아니라 콘텐츠의 역할에 따라 구분할 수 있습니다.
- 짧은 마크업을 읽고 요소 선택이 콘텐츠의 의미와 맞는지 판단할 수 있습니다.

## 20분 학습 순서

1. 3분: 요소 이름 없이 만든 페이지를 관찰합니다.
2. 8분: 문서의 큰 구조와 의미론적 요소를 이해합니다.
3. 6분: 같은 콘텐츠를 의미에 맞게 다시 읽고 판단합니다.
4. 3분: 확인 문제에 자신의 말로 답합니다.

## 먼저 관찰하기

아래 마크업을 브라우저에서 보면 제목, 링크, 본문이 모두 표시될 수 있습니다. 설명을 읽기 전에 코드만 보고 다음 질문에 답해 보세요.

```html
<body>
  <div class="top">
    <h1>BAM.dev</h1>
  </div>
  <div class="menu">
    <a href="/learn">학습</a>
    <a href="/quiz">복습</a>
  </div>
  <div class="content">
    <h2>HTML 문서 구조</h2>
    <p>오늘은 요소가 맡는 역할을 구분합니다.</p>
  </div>
</body>
```

- 사이트 이름을 소개하는 영역은 어디인가요?
- 다른 화면으로 이동하는 주요 링크 묶음은 어디인가요?
- 이 페이지에서만 볼 수 있는 중심 내용은 어디인가요?
- 클래스 이름을 지우면 각 `div`의 역할을 코드만 보고 설명할 수 있나요?

HTML 요소는 단지 상자를 만드는 문법이 아닙니다. 요소 이름이 콘텐츠의 역할을 표현하면 브라우저, 검색 도구, 보조 기술, 그리고 코드를 읽는 개발자가 구조를 더 분명하게 파악할 수 있습니다.

## 문서의 큰 구조

```html
<!doctype html>
<html lang="ko">
  <head>
    <meta charset="UTF-8" />
    <meta name="viewport" content="width=device-width, initial-scale=1" />
    <title>BAM.dev HTML 학습</title>
  </head>
  <body>
    <h1>문서 구조 연습</h1>
  </body>
</html>
```

- `<!doctype html>`은 브라우저가 이 문서를 표준 HTML 방식으로 처리하도록 알립니다.
- `html`은 HTML 문서의 루트 요소입니다. `lang="ko"`는 문서 내용의 기본 언어가 한국어임을 나타냅니다.
- `head`에는 문서 제목, 문자 인코딩처럼 문서에 관한 정보가 들어갑니다.
- `body`는 제목, 문단, 링크처럼 문서의 실제 내용을 나타냅니다.

`head`와 `header`는 이름이 비슷하지만 역할이 다릅니다. `head`는 문서에 관한 정보를 담고, `header`는 `body` 안에서 페이지나 한 콘텐츠 영역의 소개를 나타냅니다.

## 의미에 따라 요소 고르기

### `header`: 페이지나 영역을 소개하는 내용

`header`는 가까운 페이지나 콘텐츠 영역의 소개 또는 탐색을 돕는 내용을 나타냅니다. 보통 제목, 짧은 설명, 로고 같은 내용이 들어갑니다. 페이지 전체에 하나만 써야 하는 요소는 아니므로 `article`이나 `section` 안에도 그 영역을 소개하는 `header`가 있을 수 있습니다.

### `nav`: 주요 이동 경로

`nav`는 다른 페이지나 현재 페이지의 부분으로 이동하는 주요 링크 영역입니다. 페이지의 모든 링크를 `nav`로 감쌀 필요는 없습니다. 예를 들어 문장 안의 참고 링크 하나는 그 자체로 충분합니다.

### `main`: 현재 문서의 중심 내용

`main`은 `body`의 중심 내용을 나타냅니다. 여러 페이지에서 반복되는 사이트 머리말, 주요 메뉴, 저작권 정보보다는 현재 페이지의 고유한 핵심 내용을 담습니다. 일반적인 문서에서는 사용자에게 보이는 `main`을 하나 두면 중심 영역을 빠르게 구분하기 쉽습니다.

### `section`: 주제로 묶인 한 구역

`section`은 하나의 주제로 묶인 문서 구역입니다. 보통 그 주제를 알려 주는 제목을 함께 둡니다. 단지 CSS를 적용하거나 JavaScript에서 찾기 위한 상자가 필요하다면 의미를 새로 만들지 않는 `div`가 더 알맞을 수 있습니다.

## 같은 콘텐츠를 다시 읽기

처음의 콘텐츠를 역할에 맞게 표현하면 다음과 같이 바꿀 수 있습니다.

```html
<body>
  <header>
    <h1>BAM.dev</h1>
  </header>

  <nav aria-label="주요 메뉴">
    <a href="/learn">학습</a>
    <a href="/quiz">복습</a>
  </nav>

  <main>
    <section aria-labelledby="html-structure-title">
      <h2 id="html-structure-title">HTML 문서 구조</h2>
      <p>오늘은 요소가 맡는 역할을 구분합니다.</p>
    </section>
  </main>
</body>
```

화면 디자인은 CSS에 따라 달라지므로 이 코드가 무조건 처음 코드와 다르게 보인다고 단정할 수는 없습니다. 중요한 차이는 요소 이름만 읽어도 소개, 주요 이동, 중심 내용, 주제 구역의 관계를 추론할 수 있다는 점입니다.

`aria-label="주요 메뉴"`는 이 탐색 영역의 이름을 제공합니다. `aria-labelledby`는 `section`의 이름을 실제 제목 요소와 연결합니다. 의미가 맞는 기본 HTML 요소를 먼저 고르고, 필요한 이름이나 관계만 접근성 속성으로 보완합니다.

## 짧은 마크업 판단하기

먼저 아래 두 질문에 답한 뒤 판단 기준을 펼쳐 읽는다고 생각해 보세요.

```html
<main>
  <section>
    <h2>학습 목표</h2>
    <p>의미론적 요소를 구분합니다.</p>
  </section>

  <section class="blue-box">
    <p>파란 배경을 적용하기 위한 묶음입니다.</p>
  </section>
</main>
```

1. 첫 번째 `section`은 어떤 하나의 주제로 묶여 있나요?
2. 두 번째 `section`을 제목 없이도 문서의 독립된 구역으로 설명할 수 있나요, 아니면 모양을 위한 상자일 뿐인가요?

### 판단 기준

- 첫 번째 영역은 “학습 목표”라는 주제와 제목이 있으므로 `section`의 의미와 맞습니다.
- 두 번째 영역이 오직 배경색 적용을 위한 묶음이라면 `section`보다 `div`가 목적에 더 정확합니다.
- 요소를 고를 때 “어떻게 보이나?”보다 “이 콘텐츠가 문서에서 무슨 역할을 하나?”를 먼저 묻습니다.

## 흔한 혼동

### `head` 대신 `header`를 쓰기

`title`이나 문자 인코딩 같은 문서 정보는 `head`에 둡니다. 사용자에게 보이는 페이지 소개는 `body` 안의 `header`에 둡니다.

### 링크 하나마다 `nav`를 쓰기

`nav`는 주요 탐색 링크 묶음을 위한 요소입니다. 본문의 단일 참고 링크까지 모두 `nav`로 감싸면 중요한 탐색 영역을 구분하기 어려워집니다.

### 모든 상자를 `section`으로 바꾸기

주제와 제목으로 설명할 수 있는 구역에는 `section`이 어울립니다. 레이아웃이나 스타일만을 위한 묶음에는 `div`가 더 정확할 수 있습니다.

### `main` 안에 반복 메뉴까지 넣기

`main`은 현재 문서의 고유한 중심 내용입니다. 여러 페이지에서 반복되는 사이트 메뉴는 보통 `main` 바깥에 둡니다.

## 확인 문제

1. `head`와 `header`의 차이를 “문서 정보”와 “사용자에게 보이는 소개”라는 말을 사용해 설명해 보세요.
2. 사이트의 주요 메뉴와 본문 속 참고 링크 중 어느 쪽이 `nav`에 더 알맞은지 이유와 함께 말해 보세요.
3. `main`에 반복되는 사이트 메뉴를 넣지 않는 이유를 자신의 말로 설명해 보세요.
4. 어떤 묶음을 `section`과 `div` 중 하나로 고를 때 먼저 던질 질문을 적어 보세요.
5. 다음 역할을 `header`, `nav`, `main`, `section`에 하나씩 연결해 보세요: 페이지 소개, 주요 이동, 현재 페이지의 중심 내용, 제목을 가진 주제 구역.
