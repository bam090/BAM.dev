# HTML 시작하기: 요소와 문서의 기본 골격

## 학습 목표

- HTML·CSS·JavaScript가 맡는 일을 구분하고 HTML 한 줄에서 태그·요소·속성을 찾을 수 있습니다.
- 요소를 중첩할 때 시작한 순서의 반대로 닫고 빈 요소를 바르게 쓸 수 있습니다.
- 문서의 기본 골격에서 `head`와 `body`를 나누고 doctype·lang·title·charset·viewport의 역할을 설명할 수 있습니다.

## HTML이란

HTML은 웹페이지에 들어갈 내용의 종류와 관계를 표시하는 언어입니다.
브라우저는 HTML을 읽고 제목·문단·링크·입력칸 같은 내용을 화면에 보여 줍니다.
웹페이지는 보통 세 기술이 함께 만듭니다.

| 기술 | 먼저 맡는 일 |
| --- | --- |
| HTML | 내용의 종류와 관계를 표시합니다. |
| CSS | 내용이 보이는 모양과 배치를 정합니다. |
| JavaScript | 사용자 행동에 반응하고 상태를 바꿉니다. |

CSS는 색과 크기 같은 꾸밈을 맡고 JavaScript는 버튼을 눌렀을 때 내용이 바뀌는 동작을 맡습니다.
세 기술은 함께 동작하지만 처음에는 각 기술이 주로 맡는 일을 기준으로 구분합니다.

> [!note]- 브라우저·웹페이지·파일이란?
> 브라우저는 Chrome이나 Safari처럼 웹페이지 파일을 읽어 화면에 보여 주는 프로그램입니다.
> 웹페이지는 브라우저에서 하나의 문서로 여는 내용입니다.
> 파일은 내용을 저장한 한 묶음이고 폴더는 여러 파일을 정리하는 상자입니다.

예를 들어 동네 독서 모임인 밤마을 책모임의 안내 페이지를 만든다고 해 보겠습니다.
이 문서는 그 페이지의 첫 줄부터 문서 전체의 뼈대까지 차례로 만들어 봅니다.

## HTML 요소의 구조

책모임 안내에 들어갈 문장 하나를 HTML로 써 보겠습니다.

```html
<p class="notice">모임은 오후 7시에 시작합니다.</p>
```

이 한 줄은 세 부분으로 나눠 읽습니다.

- `<p>`와 `</p>`는 요소의 시작과 끝을 표시하는 태그입니다.
- `<p class="notice">...</p>` 전체가 하나의 `p` 요소입니다.
- `class="notice"`는 요소에 추가 정보를 주는 속성이며 시작 태그 안에 씁니다.

요소의 시작 태그와 종료 태그 사이에 다른 요소를 넣는 관계를 중첩이라고 합니다.
중첩한 요소는 시작한 순서의 반대로 닫습니다.
다음 문장에서 `em` 안에 `strong`을 넣었다면 어느 태그부터 닫아야 할지 예상해 보세요.

```html
<p>이번 모임은 <em>꼭 <strong>제시간에</strong></em> 와 주세요.</p>
```

가장 안쪽의 `strong`을 먼저 닫고 그다음 `em`·`p` 순서로 닫았습니다.
이렇게 닫으면 `p` 안에 `em`이 있고 `em` 안에 `strong`이 있는 관계가 그대로 남습니다.
반대로 `<em>꼭 <strong>제시간에</em></strong>`처럼 닫는 순서가 엇갈리면 태그가 서로 겹칩니다.
브라우저가 화면은 복구해 보여 줄 수 있지만 의도한 부모·자식 관계는 아닙니다.

> [!note]- strong과 em은 무엇이 다른가요?
> `strong`은 내용이 특히 중요하다는 뜻을 나타냅니다.
> `em`은 문장에서 힘주어 읽을 부분 곧 강세를 나타냅니다.
> 기본 모양이 굵게나 기울임으로 보여도 모양 때문에 고르지 않습니다.
> 굵기나 기울임 같은 모양만 필요하면 CSS로 정합니다.

## 빈 요소

대부분의 요소는 시작 태그와 종료 태그가 있습니다.
그러나 `img`·`input`·`meta`처럼 내용과 종료 태그가 없는 요소도 있습니다.
이런 요소를 빈 요소(void element)라고 합니다.

```html
<img src="book.jpg" alt="이번 달 책 표지">
```

빈 요소에는 `</img>` 같은 종료 태그를 쓰지 않습니다.
`<img />`처럼 끝에 `/`를 붙인 코드도 볼 수 있습니다.
HTML에서는 이 `/`가 요소를 닫는 기능을 하지 않습니다.

요소 하나를 읽고 쓸 수 있게 되었습니다.
이제 이런 요소들을 담을 문서 전체의 뼈대를 만들어 보겠습니다.

## HTML 문서의 기본 골격

HTML 파일은 다음 골격으로 시작합니다.
눈에 보이는 본문과 문서를 설명하는 정보를 나눠 두기 위해서입니다.

```html
<!doctype html>
<html lang="ko">
  <head>
    <meta charset="utf-8">
    <meta name="viewport" content="width=device-width, initial-scale=1">
    <title>밤마을 책모임</title>
  </head>
  <body>
    <h1>밤마을 책모임</h1>
    <p class="notice">모임은 오후 7시에 시작합니다.</p>
  </body>
</html>
```

`head`에는 문서 자체를 설명하거나 다른 파일과 연결하는 정보가 들어갑니다.
`body`에는 사용자가 읽고 조작할 페이지 내용이 들어갑니다.
화면의 머리말을 뜻하는 `header`는 `head`와 이름이 비슷하지만 다른 요소입니다.

골격의 각 줄은 같은 종류의 설정이 아닙니다.

| 코드 | 하는 일 | 알아 둘 점 |
| --- | --- | --- |
| `<!doctype html>` | 브라우저가 과거 문서용 호환 모드가 아니라 표준 모드로 처리하게 합니다. | 문서 맨 앞에 두는 필수 문구이며 HTML 요소나 버전 번호가 아닙니다. |
| `<html lang="ko">` | 문서 내용의 기본 언어가 한국어임을 알립니다. | 화면 낭독기의 발음과 번역 같은 문서 이해를 돕습니다. |
| `<title>` | 탭·방문 기록·북마크에서 문서를 구분할 이름을 정합니다. | 본문의 대표 제목인 `h1`과 역할이 다릅니다. |
| `<meta charset="utf-8">` | 파일의 바이트를 어떤 문자로 읽을지 선언합니다. | 실제 파일도 UTF-8로 저장해야 합니다. |
| viewport `meta` | 작은 화면에서 처음 보이는 영역을 기기 너비에 맞추게 돕습니다. | 문법상 필수는 아니지만 화면 폭에 맞춰 배치가 바뀌는 페이지에서 흔히 쓰는 권장 설정입니다. |

viewport 설정 하나만 넣는다고 작은 화면용 배치가 완성되지는 않습니다.
CSS로 배치를 정하고 실제 좁은 화면에서 따로 확인해야 합니다.
확대를 막는 `user-scalable=no` 같은 설정은 사용자가 글자를 키울 수 없게 하므로 쓰지 않습니다.

## HTML 기초의 활용

새 HTML 파일을 만들 때는 위 골격부터 적고 `body` 안에 내용을 채웁니다.
그리고 다음을 확인합니다.

| 확인할 것 | 이유 |
| --- | --- |
| `lang`과 `title`이 실제 내용과 맞는가 | 탭 이름과 낭독 언어가 페이지를 바르게 설명합니다. |
| 중첩한 요소를 시작의 반대 순서로 닫았는가 | 의도한 부모·자식 관계가 유지됩니다. |
| 빈 요소에 종료 태그를 붙이지 않았는가 | `img`·`input`·`meta`에는 내용이 없습니다. |
| 모양만 필요한 곳에 `strong`·`em`을 쓰지 않았는가 | 모양은 CSS가 맡습니다. |

다음 문서에서는 이 `body` 안의 내용을 역할별 영역과 제목 계층으로 나눕니다.

## 정리

- HTML은 내용의 종류와 관계를 표시하고 태그·요소·속성으로 이를 적습니다.
- 중첩한 요소는 시작한 순서의 반대로 닫고 빈 요소에는 종료 태그가 없습니다.
- `head`는 문서 정보를 담고 `body`는 페이지 내용을 담습니다.

## 핵심 질문 답

시작과 끝을 표시하는 부분은 태그이고 내용까지 포함한 전체는 요소이며 시작 태그 안의 `class` 같은 정보는 속성입니다.
요소 안에 요소를 넣는 중첩은 시작한 순서의 반대로 닫고 `img`·`input`·`meta` 같은 빈 요소에는 종료 태그가 없습니다.
문서의 `head`에는 문서 정보를 두고 `body`에는 읽고 조작할 내용을 둡니다.
doctype은 표준 모드·lang은 기본 언어·title은 탭 등에 쓰는 문서 이름·charset은 문자 해석·viewport는 처음 보이는 영역을 정하며 viewport만으로 반응형 배치가 완성되지는 않습니다.
