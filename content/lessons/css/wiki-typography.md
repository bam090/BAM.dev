# 읽기 쉬운 글꼴과 줄 간격

## 학습 목표

글꼴을 사용할 수 없거나 글자·줄 간격이 커지는 상황을 고려해 대체 글꼴과 line-height를 정할 수 있습니다.

## 한줄 요약

글꼴에는 대체 후보를 두고 단위 없는 line-height로 글자 크기를 따라가며 사용자 간격 변경에도 내용을 보존합니다.

## 먼저 확인할 개념

[길이 단위의 계산 기준](#/learn/css/wiki-units)에서 글자 크기가 무엇을 기준으로 계산되는지 살펴보세요.

## 글꼴은 후보 목록으로 정한다

```css
body {
  font-family: "Pretendard", Arial, sans-serif;
  line-height: 1.6;
}
```

브라우저는 font-family 목록을 앞에서부터 확인한다.
앞 글꼴을 사용할 수 없거나 특정 글자의 모양을 제공하지 않으면 다음 후보를 사용한다.
마지막에는 sans-serif 같은 일반 글꼴 계열을 두어 읽을 수 있는 대안을 남긴다.

이 선언만으로 Pretendard 파일이 내려받아지는 것은 아니다.
글꼴 이름을 적었어도 사용자의 환경에 없을 수 있으므로, 예제에서는 대체 글꼴로도 내용을 읽을 수 있어야 한다.

## 줄 간격은 글자 크기와 함께 본다

line-height는 글줄의 높이를 정한다.
`1.6`처럼 단위 없는 수를 쓰면 각 요소의 글자 크기에 비례해 계산된다.

```css
.notice {
  font-family: Arial, sans-serif;
  line-height: 1.6;
}

.notice h2 {
  font-size: 1.25rem;
}
```

큰 제목과 본문이 같은 숫자를 이어받아도 각자의 글자 크기를 기준으로 줄 높이를 계산할 수 있다.
글자가 커지는데 고정된 높이의 상자에 가두면 문장이 겹치거나 잘릴 수 있다.

WCAG가 모든 문서의 기본 line-height를 반드시 1.5로 지정하라는 것은 아니다.
사용자가 글자와 줄 간격을 늘렸을 때 내용이나 기능이 사라지지 않아야 한다는 조건과 구분한다.

## 글꼴이 달라져도 읽을 수 있는가

같은 문구를 대체 글꼴로 표시하고 줄이 어디에서 바뀌는지 관찰해 보자.
글자 크기를 키우고 긴 제목을 넣었을 때도 본문과 버튼이 겹치지 않는지 살핀다.
원하는 글꼴로 한 번 예쁘게 보인 결과만으로 읽기 조건을 다 확인한 것은 아니다.

### 선택 확장: 웹폰트와 굵기

웹폰트는 @font-face로 제공하고 font-display로 불러오는 동안의 표시 방식을 정한다.
normal은 보통 400, bold는 보통 700에 대응하지만 해당 굵기의 파일이 없으면 브라우저가 가까운 굵기를 고르거나 비슷하게 만들 수 있다.
특정 글꼴 파일을 전제로 하기 전에 대체 글꼴의 읽기 상태부터 확인한다.

## 핵심 질문 답

font-family에 대체 후보와 일반 글꼴 계열을 두어 앞 글꼴이나 글자 모양이 없어도 읽히게 합니다.
단위 없는 line-height는 각 요소의 글자 크기를 따라 계산하게 하고, 글자·줄 간격을 늘렸을 때 내용과 조작 요소가 잘리지 않는지도 확인합니다.
특정 글꼴과 기본 크기에서 보이는 모습만으로 완료하지 않습니다.
