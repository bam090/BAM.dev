# 색과 대비로 정보 전달하기

## 학습 목표

글자와 배경의 대비를 확인하고 색 이외의 상태 단서와 알맞은 투명도 표현을 선택할 수 있습니다.

## 한줄 요약

색은 실제 배경과의 대비로 확인하며 상태를 색 하나에만 맡기지 않고 배경 알파와 요소 전체 opacity를 구분합니다.

## 먼저 확인할 개념

[CSS의 역할과 적용](#/learn/css/wiki-css-basics)에서 속성과 값의 역할을 먼저 확인해 보세요.

## 글자와 배경은 함께 비교한다

```css
.notice {
  color: rgb(22 50 79);
  background-color: rgb(237 246 255);
}
```

color는 글자색, background-color는 배경색을 정한다.
글자색 하나만 보고 잘 읽힌다고 판단할 수 없으므로 실제로 맞닿는 배경과의 대비를 확인한다.

WCAG의 일반 텍스트 대비 기준은 최소 4.5:1, 큰 텍스트는 최소 3:1이다.
큰 텍스트는 보통 굵지 않은 18pt(약 24 CSS px) 이상 또는 굵은 14pt(약 18.7 CSS px) 이상을 뜻한다.
로고·비활성 요소 등 예외도 있으므로 글자가 커 보인다는 느낌만으로 기준을 낮추지 않는다.

예제 색도 실제 사용 화면의 글자 크기와 배경 조합으로 검사한다.
이 코드가 모든 사용 조건에서 대비 검증을 마쳤다는 뜻은 아니다.

## 상태를 색 하나로만 말하지 않는다

오류 입력을 빨간색으로만 표시하면 색을 구분하기 어려운 사용자가 뜻을 놓칠 수 있다.
무엇을 고쳐야 하는지 문구와 다른 시각 단서를 함께 남긴다.

```html
<p class="field-error">
  <span aria-hidden="true">⚠</span>
  전화번호를 다시 확인해 주세요.
</p>
```

이 예에서는 경고 모양이 장식 역할을 하고 문장이 오류 내용을 전달한다.
선택·오류·현재 위치를 색 없이 보아도 알 수 있는지 확인해 보자.
문구·밑줄·테두리·모양 같은 단서를 필요에 맞게 함께 사용할 수 있다.

## 배경만 투명하게 할지 구분한다

현대 rgb 문법은 `rgb(31 111 235 / 60%)`처럼 알파 값도 받을 수 있다.
반드시 rgba라는 이름만 사용해야 하는 것은 아니다.

opacity는 배경만 흐리게 하지 않는다.
요소와 그 안의 내용을 한 장처럼 합친 전체 결과에 적용하므로 글자까지 흐려질 수 있다.
배경만 반투명하게 만들려면 알파가 있는 background-color를 먼저 검토한다.

반투명 배경에서는 그 뒤에 놓인 색도 최종 결과에 영향을 준다.
값을 고른 뒤에는 실제 배경 위에서 글자와 상태가 구분되는지 다시 살핀다.

## 핵심 질문 답

글자와 실제 배경의 대비를 크기별 기준에 맞춰 확인하고, 오류나 선택 상태에는 문구·밑줄·모양 같은 다른 단서를 함께 둡니다.
opacity는 글자를 포함한 요소 전체 결과에 적용되므로 배경만 반투명하게 하려면 배경색의 알파를 사용합니다.
투명도와 배경 조합이 달라지면 실제 대비도 다시 확인합니다.
