# 진법과 비트: 2진수와 비트 연산

## 학습 목표

- 10진수를 2진수로 바꾸고 비트 연산자 `&`·`|`·`^`·`~`·`<<`·`>>`의 결과를 자리마다 계산할 수 있습니다.
- 정수 하나의 비트로 집합을 나타내고 원소 추가·제거·확인과 부분집합 나열을 할 수 있습니다.

## 한줄 요약

2진수는 수를 0과 1의 자리로 나타낸 것이고 비트 연산은 그 자리끼리 계산하므로 정수 하나로 여러 개의 켜짐과 꺼짐을 한꺼번에 담고 다룰 수 있습니다.

## 진법이란

**진법**은 몇 개의 숫자로 수를 나타내고 몇이 되면 윗자리로 올릴지 정한 규칙입니다.
우리가 쓰는 10진법은 0부터 9까지 열 개의 숫자를 쓰고 10이 되면 한 자리 올립니다.
반면 **2진법**은 0과 1 두 개만 쓰고 2가 되면 한 자리 올립니다.

컴퓨터는 모든 정수를 2진수로 저장합니다.
2진수 한 자리를 **비트**라고 하고 Java의 `int`는 비트 32개로 이루어져 있습니다.
그래서 2진수를 알면 컴퓨터가 수를 다루는 방식을 그대로 활용할 수 있습니다.

예를 들어 민지·도윤·서아·하준 네 명의 스터디 출석을 기록한다고 해 보겠습니다.
이 문서는 이 네 명의 출석 기록으로 끝까지 설명합니다.
출석을 1·결석을 0으로 적으면 네 명의 출석이 2진수 한 개가 됩니다.

## 2진수 변환

10진수를 2진수로 바꿀 때는 2로 나눈 나머지를 모읍니다.
[나머지와 최대공약수](#/learn/algorithm/number-theory-and-geometry)에서 본 나머지 연산이 여기서 다시 쓰입니다.

![13을 2로 계속 나누는 모습. 13 나누기 2는 몫 6 나머지 1 · 6 나누기 2는 몫 3 나머지 0 · 3 나누기 2는 몫 1 나머지 1 · 1 나누기 2는 몫 0 나머지 1이다. 나머지를 아래에서 위로 읽으면 1101이고 각 자리는 8·4·2·1을 뜻해서 8 더하기 4 더하기 1은 13이다.](content/assets/algorithm/math-bits-convert.png)

13을 몫이 0이 될 때까지 2로 나누면 나머지가 1·0·1·1 순서로 나옵니다.
처음 나온 나머지가 가장 낮은 자리이므로 아래에서 위로 읽어 `1101`이 됩니다.
거꾸로 2진수를 10진수로 바꿀 때는 오른쪽부터 1·2·4·8을 곱해서 더합니다.
`1101`은 `8 + 4 + 0 + 1 = 13`입니다.

같은 방법으로 3으로 나누면 3진수가 되고 16으로 나누면 16진수가 됩니다.
`n`진수는 `n`으로 나눈 나머지를 모은 것이기 때문입니다.
16진수는 10부터 15까지를 `A`부터 `F`로 써서 13은 `D`가 됩니다.

코드로 옮기면 나머지를 앞에 붙여 가는 반복문입니다.

```java
static String toBinary(int n) {
    String digits = "";
    while (n > 0) {
        digits = (n % 2) + digits;
        n /= 2;
    }
    return digits;
}
```

`toBinary(13)`이 어떤 문자열을 돌려줄지 그림과 비교해 예상해 보세요.

```text
13의 2진수: 1101
```

`digits`는 `1` → `01` → `101` → `1101` 순서로 자라납니다.
새 나머지를 앞에 붙이기 때문에 처음 나온 나머지가 맨 오른쪽 자리에 남습니다.

## 비트로 집합 나타내기

이제 2진수의 자리 하나하나에 스터디원을 한 명씩 맡겨 보겠습니다.
가장 오른쪽 자리를 0번 비트로 두고 0번은 민지·1번은 도윤·2번은 서아·3번은 하준입니다.
그러면 월요일 출석을 정수 하나로 적을 수 있습니다.

![4칸짜리 비트 줄. 오른쪽부터 0번 민지 · 1번 도윤 · 2번 서아 · 3번 하준이다. 월요일은 1101로 민지·서아·하준이 1이고 도윤이 0이라 정수 13이다. 화요일은 0110으로 도윤·서아가 1이라 정수 6이다.](content/assets/algorithm/math-bits-set.png)

월요일에는 민지·서아·하준이 출석했으므로 `1101`이고 10진수로 13입니다.
화요일에는 도윤·서아가 출석했으므로 `0110`이고 10진수로 6입니다.
이렇게 정수의 비트로 집합을 나타내는 방법을 **비트마스크**라고 합니다.
`int` 하나에 비트가 32개 있으므로 원소가 32개 이하인 집합은 정수 하나로 담을 수 있습니다.

## 비트 연산자

**비트 연산자**는 두 정수를 2진수로 놓고 같은 자리끼리 계산하는 연산자입니다.
월요일 13과 화요일 6에 비트 연산을 해 보면 출석부에 대한 질문이 연산 한 번으로 풀립니다.

![월요일 1101과 화요일 0110을 자리마다 맞춰 놓은 표. 앤드는 둘 다 1인 자리만 1이라 0100이고 서아다. 오어는 하나라도 1이면 1이라 1111이고 네 명 모두다. 엑스오어는 둘이 다를 때만 1이라 1011이고 민지·도윤·하준이다.](content/assets/algorithm/math-bits-ops.png)

| 연산자 | 규칙 | 월요일 13 · 화요일 6 | 출석부에서 뜻 |
| --- | --- | --- | --- |
| `&` (AND) | 둘 다 1이면 1 | `1101 & 0110 = 0100` → 4 | 이틀 모두 온 사람 (서아) |
| `|` (OR) | 하나라도 1이면 1 | `1101 | 0110 = 1111` → 15 | 한 번이라도 온 사람 (전원) |
| `^` (XOR) | 서로 다르면 1 | `1101 ^ 0110 = 1011` → 11 | 하루만 온 사람 (민지·도윤·하준) |
| `~` (NOT) | 0과 1을 뒤집음 | `~1101` → `0010` | 월요일에 안 온 사람 (도윤) |

집합으로 보면 `&`는 교집합이고 `|`는 합집합입니다.
`^`는 한쪽에만 있는 원소를 모으고 `~`는 여집합을 만듭니다.

그런데 `~13`을 그대로 출력하면 2가 아니라 `-14`가 나옵니다.
`~`는 `int`의 비트 32개를 모두 뒤집어서 네 칸 밖의 0들까지 1로 바꿉니다.
Java의 `int`는 맨 왼쪽 비트가 1이면 음수로 읽기 때문에 결과가 음수가 됩니다.
그래서 네 명 범위만 보려면 `~13 & 15`처럼 `1111`과 한 번 더 `&`를 합니다.

### 시프트 연산자

**시프트 연산자**는 비트 전체를 왼쪽이나 오른쪽으로 밀어 옮깁니다.
`1 << 2`는 1을 왼쪽으로 두 칸 밀어서 `100`이 되고 10진수로 4입니다.
즉 `1 << k`는 `k`번 비트 하나만 켜진 수라서 `k`번 스터디원을 가리키는 표시가 됩니다.

반대로 `13 >> 2`는 `1101`을 오른쪽으로 두 칸 밀어 `11`이 되고 10진수로 3입니다.
밀려난 오른쪽 두 자리는 사라집니다.
왼쪽으로 한 칸 밀면 2를 곱한 값이 되고 오른쪽으로 한 칸 밀면 2로 나눈 몫이 됩니다.

이제 두 연산자를 합쳐 출석부를 고쳐 보겠습니다.

| 하고 싶은 일 | 식 | 월요일 13에 적용한 결과 |
| --- | --- | --- |
| 1번 도윤을 출석으로 추가 | `mask | (1 << 1)` | `1111` → 15 |
| 3번 하준을 결석으로 제거 | `mask & ~(1 << 3)` | `0101` → 5 |
| 2번 서아가 출석했는지 확인 | `(mask & (1 << 2)) != 0` | `true` |

추가는 그 자리를 1로 켜는 `|`이고 제거는 그 자리만 0인 수와 `&`해서 끄는 것입니다.
확인은 그 자리만 남겨 보고 0이 아닌지 봅니다.

## 부분집합 나열

비트마스크가 가장 빛나는 곳은 부분집합을 모두 만들어 볼 때입니다.
원소가 `n`개이면 각 원소를 넣거나 빼는 두 가지 선택이 있으므로 부분집합은 `2ⁿ`개입니다.
그리고 0부터 `2ⁿ - 1`까지의 정수가 정확히 그 `2ⁿ`개의 비트 조합과 하나씩 짝을 이룹니다.

민지·도윤·서아 세 명으로 보면 이렇습니다.

![0부터 7까지의 정수와 3자리 2진수와 그 부분집합을 나란히 놓은 표. 0은 000으로 빈 집합 · 1은 001로 민지 · 2는 010으로 도윤 · 3은 011로 민지와 도윤 · 4는 100으로 서아 · 5는 101로 민지와 서아 · 6은 110으로 도윤과 서아 · 7은 111로 세 명 모두다.](content/assets/algorithm/math-bits-subsets.png)

그래서 반복문 하나로 모든 부분집합을 차례로 만들 수 있습니다.

```java
for (int subset = 0; subset < (1 << 3); subset++) {
    System.out.println(subset + " " + members(subset));
}
```

`members`는 켜진 비트의 이름만 모아 돌려주는 메서드입니다.
출력이 몇 줄일지와 마지막 줄에 누가 있을지 먼저 예상해 보세요.

```text
0 []
1 [민지]
2 [도윤]
3 [민지, 도윤]
4 [서아]
5 [민지, 서아]
6 [도윤, 서아]
7 [민지, 도윤, 서아]
```

`1 << 3`은 8이므로 0부터 7까지 여덟 줄이 나옵니다.
부분집합을 재귀로 하나씩 만들 수도 있지만 비트마스크는 반복문 하나라서 짧고 빠릅니다.
재귀로 만드는 방법은 [백트래킹](#/learn/algorithm/brute-force-backtracking-recursion)에서 다룹니다.

Java가 제공하는 2진수 변환 메서드와 비트 개수 세기는 [Java로 정수 계산하기](#/learn/algorithm/integer-java)에서 알아봅니다.

> [!note]- 전체 코드 보기
> 이 문서의 예제를 하나로 합친 프로그램입니다.
> `AttendanceBits.java`로 저장해 실행해 볼 수 있습니다.
>
> ```java
> import java.util.ArrayList;
> import java.util.List;
>
> public class AttendanceBits {
>     static final String[] NAMES = {"민지", "도윤", "서아", "하준"};
>
>     static String toBinary(int n) {
>         String digits = "";
>         while (n > 0) {
>             digits = (n % 2) + digits;
>             n /= 2;
>         }
>         return digits;
>     }
>
>     static List<String> members(int mask) {
>         List<String> result = new ArrayList<>();
>         for (int i = 0; i < NAMES.length; i++) {
>             if ((mask & (1 << i)) != 0) result.add(NAMES[i]);
>         }
>         return result;
>     }
>
>     public static void main(String[] args) {
>         System.out.println("13의 2진수: " + toBinary(13));
>
>         int monday = 13;
>         int tuesday = 6;
>         System.out.println("월요일 " + members(monday));
>         System.out.println("화요일 " + members(tuesday));
>         System.out.println("& " + (monday & tuesday) + " " + members(monday & tuesday));
>         System.out.println("| " + (monday | tuesday) + " " + members(monday | tuesday));
>         System.out.println("^ " + (monday ^ tuesday) + " " + members(monday ^ tuesday));
>         System.out.println("~ " + (~monday) + " " + members(~monday & 15));
>         System.out.println("<< " + (1 << 2));
>         System.out.println(">> " + (monday >> 2));
>
>         int mask = monday;
>         mask = mask | (1 << 1);
>         System.out.println("도윤 추가 " + members(mask));
>         mask = monday & ~(1 << 3);
>         System.out.println("하준 제거 " + members(mask));
>         System.out.println("서아 출석? " + ((monday & (1 << 2)) != 0));
>
>         for (int subset = 0; subset < (1 << 3); subset++) {
>             System.out.println(subset + " " + members(subset));
>         }
>     }
> }
> ```

## 비트 연산의 활용

코딩테스트에서 비트 연산은 이런 곳에 씁니다.

| 문제에 나오는 말 | 쓰는 방법 |
| --- | --- |
| 원소 20개 이하의 모든 부분집합·선택 조합 | `0`부터 `(1 << n) - 1`까지 반복 |
| 켜짐과 꺼짐·방문 여부를 한 번에 저장 | 비트마스크로 상태를 정수 하나에 담기 |
| 두 집합의 공통·합치기·차이 | `&`·`|`·`^` |
| 짝수·홀수 확인 | `(x & 1) == 0`이면 짝수 |
| 2의 거듭제곱 곱하기·나누기 | `<<`·`>>` |

부분집합은 `2ⁿ`개라서 원소가 20개면 약 100만 개이고 30개면 약 10억 개입니다.
그래서 원소가 20개 정도까지일 때 비트마스크로 전부 만들어 보는 풀이를 고릅니다.
지수를 2진수로 보는 관점은 [빠른 거듭제곱](#/learn/algorithm/fast-power)에서 다시 쓰입니다.

## 정리

- 2진수는 2로 나눈 나머지를 아래에서 위로 읽어 만들고 각 자리는 오른쪽부터 1·2·4·8을 뜻합니다.
- 비트 연산자는 같은 자리끼리 계산하며 `&`는 교집합 · `|`는 합집합 · `^`는 한쪽에만 있는 원소 · `~`는 여집합입니다.
- `1 << k`는 `k`번 원소를 가리키고 `|`로 추가 · `& ~`로 제거 · `&` 뒤 `0`과 비교해 확인합니다.
- 원소 `n`개의 부분집합 `2ⁿ`개는 `0`부터 `(1 << n) - 1`까지의 정수와 하나씩 짝을 이룹니다.

## 핵심 질문 답

2진수는 수를 0과 1의 자리로 나타낸 것이고 자리마다 하나의 원소를 맡기면 정수 하나가 집합 하나가 됩니다.
비트 연산자는 같은 자리끼리 계산하므로 `&`로 교집합 · `|`로 합집합 · `^`로 한쪽에만 있는 원소를 연산 한 번에 구합니다.
`1 << k`로 `k`번 원소를 가리켜서 추가·제거·확인을 하고 `0`부터 `(1 << n) - 1`까지 반복해서 모든 부분집합을 만듭니다.
