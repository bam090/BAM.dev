# 02. 값·변수·연산자·제어문

## 학습 목표

- 글자, 숫자, 참·거짓이 서로 다른 종류의 값임을 이해합니다.
- `const`와 `let` 중 알맞은 선언을 선택할 수 있습니다.
- `=`, `+=`, `===`처럼 값을 바꾸거나 확인하는 기본 연산자를 읽을 수 있습니다.
- `if`와 `for...of`로 실행할 코드와 반복할 코드를 정할 수 있습니다.

## 1. 값과 타입은 무엇인가요?

프로그램이 기억하는 실제 정보를 **값**이라고 합니다.
값의 종류를 **타입**이라고 합니다.

| 타입 | 예 | 의미 |
| --- | --- | --- |
| `string` | `"김밥"` | 따옴표로 감싼 글자입니다. |
| `number` | `3000` | 계산에 사용하는 숫자입니다. |
| `boolean` | `true`, `false` | “예”와 “아니요”처럼 참·거짓을 나타냅니다. |
| `null` | `null` | 값이 없음을 일부러 표시합니다. |
| `undefined` | `undefined` | 아직 값이 정해지지 않은 상태를 나타냅니다. |

JavaScript에서는 변수 이름 앞에 타입을 따로 적지 않습니다.
각 값이 자신의 타입을 가집니다.

## 2. 변수는 값에 붙인 이름입니다

**변수**는 값을 나중에 다시 사용하려고 붙인 이름입니다.

```javascript
const menu = "김밥";
let orderCount = 1;

orderCount = orderCount + 1;
console.log(orderCount); // 2
```

- `const`는 같은 이름에 다른 값을 다시 대입하지 않을 때 사용합니다.
- `let`은 값이 바뀌어 같은 이름에 다시 대입해야 할 때 사용합니다.

처음에는 `const`로 선언하고, 값이 바뀌어야 할 때 `let`을 사용하는 습관이 코드를 읽기 쉽게 합니다.

`=`는 오른쪽 값을 왼쪽 이름에 대입합니다.
따라서 `orderCount = orderCount + 1`은 다음 순서로 읽습니다.

1. 현재 `orderCount`의 값 `1`에 `1`을 더합니다.
2. 결과 `2`를 다시 `orderCount`에 대입합니다.

같은 일을 `orderCount += 1`로 짧게 쓸 수도 있습니다.
숫자 변수에서 `+= 1`은 “현재 값에 `1`을 더하고, 그 결과를 다시 대입한다”라고 읽습니다.
따라서 퀴즈의 `truthyCount += 1`도 현재 횟수를 `1`만큼 늘린다는 뜻입니다.

## 3. 연산자는 값을 바꾸고 확인합니다

**연산자**는 값을 계산하거나 비교하고, 조건을 만들 때 쓰는 기호나 낱말입니다.

| 기호 | 뜻 | 예와 결과 |
| --- | --- | --- |
| `+`, `-`, `*`, `/` | 숫자를 계산합니다. | `3 + 2` → `5` |
| `>=`, `<` | 값의 크기를 비교합니다. | `20 >= 18` → `true` |
| `===` | 타입을 바꾸지 않고 같은지 비교합니다. | `3 === 3` → `true` |
| `&&` | 두 조건이 모두 참인지 확인합니다. | `true && false` → `false` |

`=`와 `===`는 하는 일이 다릅니다.

- `=`는 값을 대입합니다.
- `===`는 두 값을 비교하고 `true` 또는 `false`를 만듭니다.

`===`는 비교할 때 값의 타입을 자동으로 맞추지 않습니다.

```javascript
console.log(0 === false); // false
```

숫자 `0`과 참·거짓 값 `false`는 타입이 다르므로 결과는 `false`입니다.

`!==`는 `===`와 반대로 “두 값이 다른가?”를 확인합니다.
이 연산자도 비교할 때 타입을 자동으로 맞추지 않습니다.

```javascript
console.log(3 !== "3"); // true
```

숫자 `3`과 글자 `"3"`은 타입이 다르므로 결과는 `true`입니다.

### 조건을 합치거나 반대로 바꾸기

값 자체를 `&&`로 연결하면 왼쪽이 거짓 같은 값일 때 왼쪽 값을, 참 같은 값일 때 오른쪽 값을 고릅니다.

`||`는 “또는”이라는 뜻입니다.
양쪽이 조건일 때 하나라도 참이면 결과가 참입니다.
값 자체를 연결하면 왼쪽이 참 같은 값일 때 왼쪽 값을, 거짓 같은 값일 때 오른쪽 값을 고릅니다.

`!`는 뒤에 오는 값을 참이나 거짓처럼 판단한 다음 결과를 반대로 바꿉니다.
따라서 `!value`는 “`value`가 거짓 같은 값인가?”라고 읽을 수 있습니다.

```javascript
const isWeekend = false;
const isHoliday = true;

console.log(0 && 10);                // 0
console.log("김밥" && 10);           // 10
console.log(isWeekend || isHoliday); // true
console.log(0 || 10);                // 10
console.log(!isHoliday);             // false
console.log(!"");                    // true
```

따라서 `0 && 10`은 `0`, `"김밥" && 10`은 `10`이 됩니다.
`0 || 10`은 거짓 같은 값인 `0` 대신 오른쪽 값 `10`을 고릅니다.

### 값의 타입 확인하기

`typeof 값`은 값의 타입 이름을 글자로 알려 줍니다.

```javascript
console.log(typeof "김밥"); // "string"
console.log(typeof 3000);   // "number"
console.log(typeof true);   // "boolean"
```

`typeof value !== "string"`은 “`value`의 타입이 글자가 아닌가?”라고 읽습니다.
단, `typeof null`은 오래된 규칙 때문에 `"object"`이므로 `typeof`가 모든 값을 완벽하게 구분하지는 못합니다.

### 조건으로 값 하나 고르기

조건에 따라 값 하나를 고를 때는 **조건 연산자**를 사용할 수 있습니다.
물음표와 쌍점이 들어가서 **삼항 연산자**라고도 부릅니다.

```javascript
const age = 70;
const label = age >= 18 ? "성인" : "미성년";

console.log(label); // "성인"
```

`?` 앞의 조건이 참이면 첫 번째 값을 고릅니다.
조건이 거짓이면 `:` 뒤의 값을 고릅니다.
실행할 문장이 길어지면 삼항 연산자보다 `if...else`가 읽기 쉽습니다.

## 4. 조건문은 실행할 길을 고릅니다

**조건문**은 조건의 결과에 따라 실행할 코드를 고르는 문장입니다.

```javascript
const age = 70;
const hasTicket = true;

if (age >= 18 && hasTicket) {
  console.log("입장할 수 있습니다.");
} else {
  console.log("입장할 수 없습니다.");
}
```

- `if`는 괄호 안의 조건이 참일 때 첫 번째 코드를 실행합니다.
- `&&`는 양쪽 조건이 모두 참인지 확인합니다.
- `else`는 조건이 거짓일 때 실행할 코드를 적는 곳입니다.
- 선택지가 더 많으면 `else if`로 조건을 추가할 수 있습니다.

### 조건에서 값이 판단되는 방법

`if` 안에 값 자체를 쓰면 JavaScript는 그 값을 참이나 거짓처럼 판단합니다.

- 처음에 자주 만나는 거짓 같은 값은 `false`, `0`, 빈 글자 `""`, `null`, `undefined`, `NaN`입니다.
- 그 밖의 일반적인 값은 참처럼 판단합니다.
- 빈 배열 `[]`과 빈 객체 `{}`도 객체이므로 참처럼 판단합니다.

`undefined`는 아직 값이 정해지지 않은 상태에서 자주 만납니다.
`NaN`은 숫자 계산에 실패했음을 나타내는 값입니다.

처음에는 `score >= 60`처럼 결과가 분명히 `true` 또는 `false`가 되는 조건을 쓰는 편이 읽기 쉽습니다.

## 5. 반복문은 같은 일을 되풀이합니다

여러 값을 하나씩 읽으며 같은 일을 해야 할 때 **반복문**을 사용합니다.

```javascript
const menus = ["김밥", "라면", "떡볶이"];

for (const menu of menus) {
  console.log(menu);
}
```

`["김밥", "라면", "떡볶이"]`처럼 여러 값을 순서대로 묶은 것을 **배열**이라고 합니다.
배열은 4단원에서 자세히 배웁니다.

`for...of`는 배열의 값을 처음부터 끝까지 하나씩 꺼냅니다.
위 코드는 `김밥`, `라면`, `떡볶이`를 차례대로 출력합니다.

## 실행 가능한 최소 예제

다음 코드를 `main.js`에 저장하세요.

```javascript
const prices = [1200, 800, 1500];
let total = 0;

for (const price of prices) {
  if (price >= 1000) {
    total += price;
  }
}

console.log(total);
console.log(total === 2700);
```

같은 폴더에서 다음 명령을 실행합니다.

```bash
node main.js
```

결과는 다음과 같습니다.

```text
2700
true
```

## 실행 흐름

1. `prices`에 숫자 세 개를 순서대로 연결합니다.
2. 합계를 기억할 `total`을 `0`으로 시작합니다.
3. 첫 번째 값 `1200`은 `1000` 이상이므로 `total += price`로 더합니다. `total`은 `1200`이 됩니다.
4. 두 번째 값 `800`은 조건이 거짓이므로 더하지 않습니다.
5. 세 번째 값 `1500`은 조건이 참이므로 `total += price`로 더합니다. `total`은 `2700`이 됩니다.
6. 반복이 끝나면 `2700`을 출력합니다.
7. `total === 2700`의 비교 결과인 `true`를 출력합니다.

## 간단 Q&A

**Q. 무조건 `const`만 사용하면 되나요?**

A. 아닙니다. 같은 이름에 새 값을 다시 대입해야 할 때는 `let`을 사용합니다.

**Q. `=`와 `===`는 같은 뜻인가요?**

A. 아닙니다. `=`는 값을 대입하고, `===`는 두 값을 비교합니다.

**Q. 빈 배열 `[]`은 비어 있으니 거짓인가요?**

A. 아닙니다. 빈 장바구니도 장바구니 자체는 있는 것처럼, 빈 배열과 빈 객체는 조건문에서 참처럼 판단됩니다.

**Q. `"3" + 2`는 왜 `5`가 아닌가요?**

A. `"3"`은 글자이므로 `+`가 두 값을 이어 붙여 `"32"`를 만듭니다. 숫자 계산이 필요하면 `Number("3") + 2`처럼 먼저 숫자로 바꿉니다.

## 핵심 요약

- 값은 프로그램이 기억하는 정보이고, 타입은 값의 종류입니다.
- 변수는 값을 다시 사용하려고 붙인 이름입니다.
- `const`는 다시 대입하지 않을 때, `let`은 다시 대입할 때 사용합니다.
- `=`는 대입하고, `+=`는 더한 결과를 다시 대입합니다.
- `===`는 같은지, `!==`는 다른지를 타입을 바꾸지 않고 비교합니다.
- `||`는 하나라도 참인지 확인하고, `!`는 참과 거짓을 반대로 바꿉니다.
- `typeof`는 타입 이름을 알려 주고, 삼항 연산자는 조건에 따라 값 하나를 고릅니다.
- `if`는 실행할 길을 고르고, `for...of`는 여러 값을 하나씩 반복합니다.
- 빈 글자는 거짓처럼, 빈 배열과 빈 객체는 참처럼 판단됩니다.

먼저 자신의 말로 답한 뒤, 아래 내용을 면접관에게 설명하듯 읽어 보세요.

### 답변 1

값은 프로그램이 기억하는 실제 정보입니다.
타입은 그 값이 글자인지 숫자인지처럼 종류를 구분합니다.
변수는 그 값을 나중에 다시 사용하려고 붙인 이름입니다.

### 답변 2

`prices`에는 실행하는 동안 같은 배열이 연결되어 있으므로 `const`를 사용했습니다.
`total`에는 계산할 때마다 새로운 합계를 다시 대입하므로 `let`을 사용했습니다.

### 답변 3

`=`는 오른쪽 값을 왼쪽 이름에 대입합니다.
`===`는 타입을 바꾸지 않고 두 값이 같은지 비교합니다.
숫자 `0`과 참·거짓 값 `false`는 타입이 다르므로 `0 === false`는 `false`입니다.

### 답변 4

빈 글자 `""`는 조건문에서 거짓처럼 판단됩니다.
빈 배열 `[]`은 객체이므로 내용이 없어도 참처럼 판단됩니다.

### 답변 5

`for...of`가 가격을 `1200`, `800`, `1500` 순서로 확인합니다.
조건문은 `1000` 이상인 `1200`과 `1500`만 합계에 더합니다.
마지막에는 합계 `2700`과 `total === 2700`의 결과인 `true`를 출력합니다.
