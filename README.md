# BAM.dev · 개발자로 성장하는 나의 공간

BAM.dev는 **개념을 이해하고, 자신의 말로 설명하고 직접 코드로 옮기는 연습**을 돕는 개발 학습 서비스입니다.<br>
학습문서로 개념을 익히고 객관식으로 이해를 확인한 뒤 코드 작성과 응용 문제로 연습을 이어 갈 수 있습니다.

HTML·CSS·JavaScript부터 Java·Spring·알고리즘까지 지금 필요한 주제를 골라 자신의 속도로 공부하세요!<br>
계정이나 특정 수업 참여 없이 사용할 수 있습니다. GitHub에서 소스를 clone하거나 ZIP으로 내려받아 직접 실행할 수 있습니다.

**[BAM.dev 시작하기 →](https://bam090.github.io/BAM.dev/)**

## 바로 복습하기

설치 없이 브라우저에서 시작합니다. 문서를 먼저 읽어도, 문제부터 풀어도 됩니다. 코드 연습은 메뉴의 **Code Quest** 또는 **코딩테스트**에서 시작하세요.

| 하고 싶은 일 | 바로 가기 | 사용 방법 |
| --- | --- | --- |
| 개념 이해하기 | [학습문서](https://bam090.github.io/BAM.dev/#/learn) | 주제와 키워드로 문서를 찾고, 핵심 질문에 스스로 답한 뒤 접힌 답을 펼쳐 비교합니다. 읽은 문서는 학습 완료로 표시합니다. |
| 이해한 내용 확인하기 | [객관식 문제](https://bam090.github.io/BAM.dev/#/review) | 주제·키워드·단원을 고르고 답을 선택합니다. **정답 확인**으로 정답과 선택한 오답의 이유를 확인한 뒤 다음 문제로 넘어갑니다. |
| 공부 이어 가기 | [내 학습 기록](https://bam090.github.io/BAM.dev/#/my) | 학습 기록과 완료 결과를 확인하고, 저장된 오답에 다시 도전합니다. 진행 중인 문제는 홈이나 문제 목록의 **이어서 풀기**로 돌아갑니다. |

문제는 **하나씩 보기·전부 보기**, **개별 채점·전체 채점** 중 편한 방식으로 풀 수 있습니다. 전체 채점은 답을 고른 미채점 문제를 채점합니다.<br>
개념이 헷갈리면 **관련 개념 → 학습문서에서 자세히 보기 → 문제로 돌아가기**로 이동하세요. 같은 탭에서는 선택한 답과 채점·해설·현재 위치를 유지합니다.

학습 기록은 현재 브라우저에 저장됩니다. 이어서 공부할 때는 **같은 사이트 주소와 브라우저 프로필**을 사용하세요.<br>
공개 사이트와 로컬 실행 주소의 기록은 자동으로 동기화되지 않습니다.<br>
사이트 데이터를 지우면 기록도 사라지며, 저장이 차단된 환경에서는 현재 탭이 열린 동안만 기록을 유지합니다.

## 앞으로 추가할 기능

다음은 정식 제공 전 목표입니다. 세부 범위와 순서는 [로드맵](docs/roadmap.md)에서 확인할 수 있습니다.

- **더 세밀한 복습** — 모름·헷갈림 표시와 문제별 재도전 기능을 확장합니다.
- **더 넓은 학습 주제** — 컴퓨터 과학 기초(CS), TypeScript, React로 학습 범위를 넓힙니다.
- **Java 실행 연결과 프로젝트 실습** — 소스로 실행하는 환경의 Java 지원 방식은 별도로 설계합니다. 밤위키 원본 웹과제의 BAM.dev 연결과 공개 검증도 준비합니다.
- **학습 기록 보호** — 소스로 실행하는 브라우저 환경에서 기록 백업·복구와 안전한 저장 흐름을 보강합니다.

## 지금 공부할 수 있는 내용

현재 기본 목록에는 학습문서 **160개**, 객관식 **284문항**을 제공합니다.

| 주제 | 학습문서 | 객관식 |
| --- | ---: | ---: |
| HTML | 15 | 12 |
| CSS | 20 | 47 |
| JavaScript | 33 | 69 |
| Java | 32 | 64 |
| Spring | 46 | 92 |
| 알고리즘 | 14 | — |
| **합계** | **160** | **284** |

Java·알고리즘 문서는 Java 25를 기준으로 합니다.
Spring 과정에서는 Spring Boot·Spring Security·JPA·Spring Data JPA까지 개념을 읽고 문제로 확인합니다.<br>
현재 Spring 학습은 정적 문서와 객관식으로 제공하며 앱에서 Spring 서버나 데이터베이스를 실행하지 않습니다.

직접 작성하는 연습은 Code Quest와 코딩테스트로 나누어 제공합니다.

- **Code Quest 32개** — JavaScript 함수 12개·HTML 8개·CSS 8개는 브라우저의 공개 검사로 확인합니다.
- Java 4개는 웹에서 작성·저장하고, 검증된 로컬 prototype에서 실행합니다.
- **JavaScript 코딩테스트 6문제** — 코드를 작성하고 공개 테스트를 실행해 풀이를 점검합니다.
- **Java 코딩테스트 72문제** — 문제·예시·공개 테스트를 읽고 코드를 작성·저장합니다. 공개 테스트 실행·제출·완료 기록은 검증된 로컬 prototype에서 제공합니다.
- **HTML·CSS Web Project 1개** — 두 파일을 함께 편집하며 미리보기·공개 검사·자가평가로 결과를 확인합니다.

코딩테스트는 마지막 상세 결과를 저장해 다시 열거나 앱을 재시작해도 이어 볼 수 있습니다.
코드를 바꾸면 이전 코드의 결과임을 표시하고, 오답·문법·실행 오류·시간 초과·취소·출력 초과에 확인할 점을 안내합니다.
취소는 오답이나 성공으로 처리하지 않습니다.

**Java 실행은 검증한 macOS 환경의 별도 로컬 prototype에 한정됩니다.** 공개 웹에서는 Java 작성·저장만 가능하며 소스를 브라우저에서 실행해도 Java 실행까지 지원되는 것은 아닙니다. 설치형 앱은 주 전달 방식이 아닙니다.
자세한 실행·복원 검증 범위는 [Java Quest 기록](docs/work-items/2026-09-15-java-code-quest-runtime.md)과 [Java 코딩테스트 기록](docs/work-items/2026-09-22-java-coding-test-runtime.md)을 참고하세요.

현재 제공 범위와 다음 목표를 구분하면 다음과 같습니다.

| 학습문서 | 주제·키워드 탐색, 읽기·자기 확인·완료 기록 | 후속 주제 확장과 release 대상 콘텐츠 감사 |

| 코딩테스트 | 웹의 JavaScript 실행·Java 작성/저장, macOS prototype의 Java 공개 평가, 상세 결과 복원·오류 안내 | 소스 실행 환경의 Java 연결·저장 보호 |
| 웹과제 | 기존 인앱 HTML·CSS 과제 | 밤위키 원본의 BAM 연결·안내·공개 검증 |

## 내 컴퓨터에서 실행하기

소스를 실행하려면 **Node.js 20 이상**이 필요합니다. Git으로 복제하거나 GitHub의 **Code → Download ZIP**으로 내려받아 압축을 푸세요.
아래는 Git으로 시작하는 방법입니다. ZIP을 받았다면 압축을 푼 폴더에서 `npm run dev`를 실행하세요. 현재 브라우저 버전은 `npm install` 없이 실행되며 JDK나 Electron이 필요하지 않습니다.

```bash
git clone --branch dev https://github.com/bam090/BAM.dev.git BAM.dev
cd BAM.dev
npm run dev
```

브라우저에서 [localhost:4173](http://localhost:4173)을 엽니다. 종료할 때는 실행한 터미널에서 `Ctrl+C`를 누릅니다.
다른 포트가 필요하면 다음처럼 실행할 수 있습니다.

```bash
BAM_DEV_PORT=4189 npm run dev
```

이 경우 [localhost:4189](http://localhost:4189)를 엽니다. 기존 로컬 기록을 이어 쓰려면 이전과 같은 주소·포트를 유지하세요.<br>
`localhost`와 `127.0.0.1`도 기록을 따로 저장합니다.

개발 중 콘텐츠 연결·테스트·빌드를 확인하려면 다음 명령을 사용합니다.

```bash
npm run check
```

콘텐츠 스키마와 파일 연결 검사, Node 테스트, 정적 빌드를 차례로 실행하고 `dist/`를 생성합니다.<br>
현재 통합 브랜치는 `dev`이며, 공개 사이트는 `dev`의 정적 파일을 GitHub Pages로 제공합니다.
위 명령은 브라우저 버전을 실행하며 Java 로컬 prototype을 시작하지 않습니다.

## 기술과 프로젝트 문서

현재 화면은 **HTML·CSS·Vanilla JavaScript**로 만들었습니다.<br>
학습 콘텐츠는 정적 파일로 개인 진도와 풀이 기록은 브라우저의 `localStorage`로 관리합니다.<br>
React·TypeScript UI는 앞으로 작은 화면부터 단계적으로 도입할 목표입니다.

학습 자료는 공개 사용이 승인된 밤위키 자료와 공식 문서를 바탕으로 프로젝트에 포함했습니다.<br>
앱 실행 중 Obsidian 원본을 실시간으로 읽지는 않습니다. 자료별 출처와 보완 내역은 [참고자료 기록](docs/reference-audit.md)에서 확인할 수 있습니다.
