# BAM.dev · 개발자로 성장하는 나의 공간

BAM.dev는 **개념을 이해하고, 자신의 말로 설명하고, 직접 코드로 옮기는 연습**을 돕는 개발 학습 서비스입니다.<br>
학습문서로 개념을 익히고 객관식으로 이해를 확인한 뒤 코드 작성과 응용 문제로 연습을 이어 갈 수 있습니다.

HTML·CSS·JavaScript부터 Java·Spring·알고리즘까지, 지금 필요한 주제를 골라 자신의 속도로 공부하세요.<br>
계정이나 특정 수업 참여 없이 사용할 수 있습니다.

**[BAM.dev 시작하기 →](https://bam090.github.io/BAM.dev/)**

## 바로 복습하기

설치 없이 브라우저에서 시작합니다. 문서를 먼저 읽어도, 문제부터 풀어도 됩니다.

| 하고 싶은 일 | 바로 가기 | 사용 방법 |
| --- | --- | --- |
| 개념 이해하기 | [학습문서](https://bam090.github.io/BAM.dev/#/learn) | 주제와 키워드로 문서를 찾고, 핵심 질문에 스스로 답한 뒤 접힌 답을 펼쳐 비교합니다. 읽은 문서는 학습 완료로 표시합니다. |
| 이해한 내용 확인하기 | [객관식 문제](https://bam090.github.io/BAM.dev/#/review) | 주제·키워드·단원을 고르고 답을 선택합니다. **정답 확인**으로 정답과 선택한 오답의 이유를 확인한 뒤 다음 문제로 넘어갑니다. |
| 공부 이어 가기 | [내 학습 기록](https://bam090.github.io/BAM.dev/#/my) | 학습 기록과 완료 결과를 확인하고, 저장된 오답에 다시 도전합니다. 진행 중인 문제는 홈이나 문제 목록의 **이어서 풀기**로 돌아갑니다. |

문제는 **하나씩 보기·전부 보기**, **개별 채점·전체 채점** 중 편한 방식으로 풀 수 있습니다. 전체 채점은 답을 고른 미채점 문제를 채점합니다.<br>
개념이 헷갈리면 **관련 개념 → 학습문서에서 자세히 보기 → 문제로 돌아가기**로 이동하세요. 같은 탭에서는 선택한 답과 채점·해설·현재 위치를 유지합니다.

학습 기록은 현재 브라우저에 저장됩니다. 이어서 공부할 때는 **같은 사이트 주소와 브라우저 프로필**을 사용하세요.<br>
공개 사이트와 로컬 실행 주소의 기록은 자동으로 동기화되지 않습니다.<br>
사이트 데이터를 지우면 기록도 사라지며, 저장이 차단된 환경에서는 현재 탭이 열린 동안만 기록을 유지합니다.

## 앞으로 추가할 기능

현재 웹에서 제공하는 학습 경험을 바탕으로 다음 기능을 준비하고 있습니다. 아래 항목은 정식 제공 전 목표이며, 세부 범위와 순서는 [로드맵](docs/roadmap.md)에서 관리합니다.

- **더 세밀한 복습** — 모름·헷갈림 표시와 문제별 재도전 기능을 확장합니다.
- **더 넓은 학습 주제** — 컴퓨터 과학 기초(CS), TypeScript, React로 학습 범위를 넓힙니다.
- **Java 코드 실행과 프로젝트 실습** — 작성한 Java 코드를 실제 실행·채점하는 기능을 준비합니다. 웹과제는 밤위키에서 만든 과제를 원본으로 활용하며, BAM.dev 연결·시작 버전·공개 검증은 후속 작업입니다.
- **설치해서 쓰는 학습 앱** — 설치 후 인터넷 없이도 핵심 학습을 이어 갈 수 있는 개인 학습 공간을 목표로 합니다.

## 지금 공부할 수 있는 내용

현재 기본 목록에는 학습문서 **160개**, 객관식 **284문항**을 제공합니다.

| 주제 | 학습문서 | 객관식 |
| --- | ---: | ---: |
| HTML | 15 | 12 |
| CSS | 20 | 47 |
| JavaScript | 33 | 69 |
| Java | 32 | 64 |
| Spring | 46 | 92 |
| 알고리즘 | 14 | — |
| **합계** | **160** | **284** |

Java·알고리즘 문서는 Java 25를 기준으로 합니다. Spring 과정에서는 Spring Boot·Spring Security·JPA·Spring Data JPA까지 개념을 읽고 문제로 확인합니다.<br>
현재 Spring 학습은 정적 문서와 객관식으로 제공하며, 앱에서 Spring 서버나 데이터베이스를 실행하지 않습니다.

직접 작성하는 연습은 Code Quest와 코딩테스트로 나누어 제공합니다. 현재 작업본에는 **Code Quest 32개·코딩테스트 78문제**가 등록되어 있습니다. 콘텐츠·관련 자동 검사·대표 데스크톱 화면·독립 문서·통합 검증을 통과했고, PR #22의 원격 CI도 통과했습니다. 이후 PR #22·#23은 병합됐습니다. 아래 Java CT 로컬 실행 검증은 별도 후속 작업이며 공개 웹의 Java 실행 지원을 뜻하지 않습니다. 정확한 대상과 검증 범위는 [전환 기록](docs/work-items/2026-09-15-algorithm-bridge-coding-tests.md#최종-독립-검증과-git-게시-결과)에서 확인합니다.

- **Code Quest 32개** — JavaScript 함수 12개·HTML 8개·CSS 8개는 공개 검사로 확인합니다. Java 4개는 주문 금액 pilot과 배열·조건·FIFO 준비 문제이며 작성·저장만 가능합니다.
- **JavaScript 코딩테스트 6문제** — 코드를 작성하고 공개 테스트를 실행해 풀이를 점검합니다.
- **Java 코딩테스트 72문제 · 작성·저장 가능** — Algorithm Bridge 원본 순서의 문제·예시·공개 Test 소스와 원본 학습 지원을 읽고 코드를 저장합니다. 웹에서는 실행하지 않으며, 검증한 macOS 환경의 별도 로컬 prototype에서는 공개 테스트 실행·제출·완료 기록을 검증했습니다. 이전 Code Quest 주소는 대응하는 코딩테스트로 안내하며, 이전 초안은 명시적으로 가져올 수 있고 기존 코딩테스트 초안을 덮어쓰지 않습니다.
- **HTML·CSS Web Project 1개** — 두 파일을 함께 편집하며 미리보기·공개 검사·자가평가로 결과를 확인합니다.

학습문서는 보관된 27개를 포함하면 전체 187개이며, 문제에서 확인할 수 있는 개념 발췌는 177개입니다.<br>
보관 문서의 기존 주소와 학습 기록은 유지합니다.<br>
배운 개념을 직접 작성해보는 Code Quest와 코딩테스트는 별도 학습 흐름으로 제공합니다. Code Quest에서는 과정·주제별 탐색, 검색·진도 필터와 학습 지도로 문제를 찾을 수 있습니다.

## 현재 기능과 남은 범위

현재 다섯 영역의 기본 기능과 남은 범위는 다음과 같습니다. 등록·작성 가능 상태를 실제 실행이나 설치형 MVP 완료로 세지 않습니다.

| 영역 | 현재 가능한 일 | 남은 핵심 |
| --- | --- | --- |
| 학습문서 | 주제·키워드 탐색, 읽기·자기 확인·완료 기록 | 후속 주제 확장과 release 대상 콘텐츠 감사 |
| 객관식 | 두 보기·두 채점 방식, 해설·문서 왕복, 즉시 재도전 | 모름·헷갈림과 문제별 전체 이력 |
| Code Quest | 탐색·작성·저장, JavaScript·HTML·CSS 공개 검사 | Java 실제 실행·완료 판정 |
| 코딩테스트 | 웹의 JavaScript 실행·Java 작성/저장, macOS prototype의 Java 공개 평가·완료 기록 | 정식 설치본과 지원 OS 확정 |
| 웹과제 | 기존 인앱 HTML·CSS 과제 | 밤위키 원본의 BAM 연결·안내·공개 검증 |

설치형 오프라인 앱과 React·TypeScript 이관은 별도 장기 목표입니다. 다섯 영역 전체와 설치형 MVP가 모두 완료된 상태는 아닙니다. [웹과제 원본 활용 계약](docs/designs/web-assignments.md)과 [MVP 완료 조건](docs/product-scope.md#mvp-완료-조건)을 구분해 관리합니다.

## 내 컴퓨터에서 실행하기

코드를 살펴보거나 로컬에서 실행하려면 **Git과 Node.js 20 이상**이 필요합니다. 현재 외부 패키지 의존성이 없어 `npm install` 없이 실행할 수 있습니다.

```bash
git clone --branch dev https://github.com/bam090/BAM.dev.git BAM.dev
cd BAM.dev
npm run dev
```

브라우저에서 [localhost:4173](http://localhost:4173)을 엽니다. 종료할 때는 실행한 터미널에서 `Ctrl+C`를 누릅니다. 다른 포트가 필요하면 다음처럼 실행할 수 있습니다.

```bash
BAM_DEV_PORT=4189 npm run dev
```

이 경우 [localhost:4189](http://localhost:4189)를 엽니다. 기존 로컬 기록을 이어 쓰려면 이전과 같은 주소·포트를 유지하세요.<br>
`localhost`와 `127.0.0.1`도 기록을 따로 저장합니다.

개발 중 콘텐츠 연결·테스트·빌드를 확인하려면 다음 명령을 사용합니다.

```bash
npm run check
```

콘텐츠 스키마와 파일 연결 검사, Node 테스트, 정적 빌드를 차례로 실행하고 `dist/`를 생성합니다.<br>
현재 통합 브랜치는 `dev`이며, 공개 사이트도 `dev`의 정적 파일을 GitHub Pages로 제공합니다. PR #22·#23 병합은 기존 기준선이며, 이번 Java 코딩테스트 실행 변경의 게시 완료를 뜻하지 않습니다.

이 작업본은 브라우저 콘텐츠·화면과 로컬 Java Quest 검증용 소스를 포함합니다. 웹에서는 Java 코드를 작성·저장할 수 있습니다. 별도 macOS 검증용 prototype은 Java Quest와 Java 코딩테스트의 공개 평가·취소·기록 복원을 검증했습니다. 검증한 macOS 환경에 한정하며 정식 설치본은 아직 제공하지 않습니다. 브라우저 사용에 JDK나 Electron 설치가 필요하지 않습니다.

## 기술과 프로젝트 문서

현재 화면은 **HTML·CSS·Vanilla JavaScript**로 만들었습니다.<br>
학습 콘텐츠는 정적 파일로 개인 진도와 풀이 기록은 브라우저의 `localStorage`로 관리합니다.<br>
React·TypeScript UI는 앞으로 작은 화면부터 단계적으로 도입할 목표입니다.

학습 자료는 공개 사용이 승인된 밤위키 자료와 공식 문서를 바탕으로 프로젝트에 포함했습니다.<br>
앱 실행 중 Obsidian 원본을 실시간으로 읽지는 않습니다. 자료별 출처와 보완 내역은 [참고자료 기록](docs/reference-audit.md)에서 확인할 수 있습니다.
