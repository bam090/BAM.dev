# ADR 0001: 1차는 런타임 의존성 없이 구현한다

- 상태: 채택
- 날짜: 2026-08-16

## 결정

HTML, CSS, ES modules와 Node.js 내장 기능만 사용합니다. 개발 서버, 정적 빌드, 테스트, 콘텐츠 검증도 저장소의 작은 스크립트로 제공합니다.

## 이유

- 1~3차의 로컬 단독 사용 조건을 가장 단순하게 충족합니다.
- 프레임워크 참고 코드를 잘못 복사할 가능성을 줄입니다.
- 의존성 설치 없이 바로 실행할 수 있습니다.

## 결과

복잡한 Markdown이나 코드 편집 기능이 필요해질 때 직접 구현 비용이 커질 수 있습니다. 그 시점에는 보안·접근성·번들 크기 이점을 비교하고 정확한 버전으로 의존성을 추가합니다.
