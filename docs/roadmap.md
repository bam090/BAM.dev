| --- | --- | --- |
| 0차 기반 구축 | 완료 | 프로젝트, 테스트, 디자인 토큰, 스키마, 문서, CI, CodeRabbit |
| 1차 JavaScript 학습 | 완료 | 7개 교안 탐색, 이전·다음, 완료/진도 유지, 반응형 |
| 2차 객관식 복습 | 완료 | 14문항, 즉시 채점, 정답·모든 오답 설명, 결과·오답 저장, 독립 검증 |

| 확장 검증 게이트 | 완료 | HTML·CSS·Java 교안·객관식 샘플 각 1개, 언어 전환, 공통 스키마·라우팅 검증 |
