## 교육 범위와 출처

작성자는 승인된 CSS 문서와 기존 문항을 비교한 선행 계획을 남겼고 총괄은 새 A/E/C 근거를 확인한 뒤 작성을 진행시켰다. 아래는 작성자 최종 인계의 ID·경험 근거를 보존한 관리 기록이다. 목표·질문·직접답·정답·보기 전체는 실제 curriculum·본문·퀴즈 JSON이 정본이며 문서 담당이 교육 문장을 새로 집필하지 않았다.

CSS는 기존 활성 문서 본문을 그대로 사용하고 기존 문항 객체를 보존했다. 기존 conceptIds로 모든 새 문항이 연결되어 CSS 교안 metadata는 수정하지 않았다. 추가 발췌 중 overflow는 선행어가 빠진 구간 대신 같은 본문의 `핵심 질문 답` 연속 세 문장을 선택했다.

Spring 대응 원문은 승인된 공개 밤위키 학습자료의 파일명·본문 검색에서 찾지 못했다. `source.kind: bam-authored`는 명시 승인에 따라 에이전트가 공식 자료를 읽고 새로 작성한 프로젝트 콘텐츠 분류다. 사용자 직접 집필·위키 반입으로 표시하지 않고 원문 import 필드·SHA를 만들지 않았다. 공식 사실 확인일은 2026-09-14이며 정적 기술 기준은 정식 Java 25·preview 없음, Spring Framework 7.0.9·Spring Boot 4.1.1이다. 라이브러리 채택·컴파일·Spring/JUnit/서버 실행 결과를 뜻하지 않는다.

## 경험 등록과 최종 연결

### CSS 공통 경험 카드

작업 ID는 이 카드와 같으며 CSS 작성자는 각 행의 활성 교안과 그 선수 절을 근거로 삼았다. 기존 CSS 판단 공백을 보강하기 위한 묶음으로, 새 경험과 기존 재사용은 각 행에 구분한다. 학습자가 찾을 단서는 아래 공개 전제의 대상·관계·속성값이며 문항 첫 부분에서 고를 결과나 변경을 묻는다. 자기 설명은 실제 문항의 `learningObjective`를 “이 조건에서는 … 때문에 …이다”로 설명하는 것이다.

지원은 L1 한 행동·L2 조건 적용, E가 있는 행의 짧은 L3 관찰이다. 코드·폴더·환경과 네 보기를 공개하고 선택 뒤 모든 보기 이유를 제공한다. T는 N/A이며 객관식 선택을 독립 구현·무힌트 전이 성과로 세지 않는다. 독립 검증은 문항별 공개 전제·유일한 정답·세 오답의 근거·실제 활성 문서/concept·새 A/E/C와 첫 독해의 명확성을 확인한다. 원문 확인일 2026-09-02와 이번 공식 근거 확인일 2026-09-14를 구분한다.
